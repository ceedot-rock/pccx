# PCCX law

There is one codec. Its name is PCCX. The file is PCC1.

Every own-path seat is a muscle on that body. None of them is a product.

Seats:
- ZERO / TRU8 / TR8X
- MATCH (LBR1 parse + champ pack + delta)
- BWT (pulsar BW22/BW23)
- AWARE (Combined GC own-path; host gzip/xz/bz rejected)
- CMAQ, LZW1, LZM1, STR1 when the file is still fat

Rule: encode each seat that is allowed on this class and size. Keep the smallest DECODE_OK blob. That blob is PCCX.

Not a leaderboard of names. One write.
